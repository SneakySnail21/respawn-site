# Respawn

Игровой портал: новости, обзоры, гайды, карточки игр с оценками игроков, форум в стиле Reddit, блоги участников, закладки и подписки на рубрики. Стиль: тёмный, оранжевый акцент, шрифты Onest и Unbounded.

- **Живой сайт** (регистрация, форум, оценки, закладки, свои статьи): https://respawn.1c-freelancer.ru/
- **Копия для чтения на GitHub Pages**: https://sneakysnail21.github.io/respawn-site/

## Что здесь лежит

| Папка | Содержимое |
|---|---|
| `docs/` | Статичная копия сайта (то, что показывает GitHub Pages) |
| `respawn-portal/` | Тема WordPress: шаблоны, стили, анимации, интро-презентация |
| `respawn-core/` | Плагин WordPress: игры и форум на игру, оценки, голосования, закладки, подписки, регистрация на сайте, Respawn AI |
| `tools/` | `static-export.mjs` собирает копию для GitHub Pages, `serve.mjs` показывает её локально |
| `DEPLOY.md` | Как перенести сайт на другой хостинг и как обновлять копию |
| `DESIGN.md` | Описание оформления |

## Что работает на GitHub Pages, а что нет

GitHub Pages отдаёт только готовые файлы и не запускает PHP и базу данных. Поэтому в копии можно читать материалы, листать игры и форум, смотреть интро-презентацию, а регистрация, лайки, оценки, закладки и написание статей работают только на живом сайте. Ссылки на них ведут туда.

## Обновление копии

Копия обновляется автоматически: после каждого утреннего и вечернего выпуска статей (09:00 и 19:00) компьютер владельца пересобирает `docs/` и отправляет изменения сюда. Вручную это делается так:

```
cd tools
node static-export.mjs --public=https://sneakysnail21.github.io/respawn-site --main=https://respawn.1c-freelancer.ru --out=../docs
```

Затем закоммитить и отправить изменения: GitHub Pages обновится сам. Скрипт убирает счётчики и теги аналитики, ссылки на REST API и страницы, которым нужен PHP.

## Права и правки

Код опубликован для просмотра. Изменять репозиторий может только владелец: другие пользователи могут смотреть файлы, скачивать копию и предлагать правки через Issues, но не могут менять ветку `main`. Лицензия не выбрана, поэтому по умолчанию все права сохранены за автором: копировать, распространять и использовать код в своих проектах без разрешения нельзя.
